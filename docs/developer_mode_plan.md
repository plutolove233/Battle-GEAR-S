# 开发者测试模式 - 实施计划

## 目标
创建游戏内开发者调试工具，支持对玩家状态的完全掌控和修改。

## 功能模块

### 1. 行动牌管理
- **查看面板**：显示所有玩家的行动牌手牌，按玩家分组
- **获得牌**：选择目标玩家 + 指定卡牌ID，添加到玩家手牌
- **弃置牌**：选择目标玩家 + 弃置数量，从手牌移除

### 2. 装备牌/框架管理
- **查看面板**：显示所有玩家的装备状态（6部件区 + 2武器区 + 2储备区 + 1事件区 + 1驾驶区）
- **获得装备**：选择玩家 + 卡牌ID，获得未设置的装备（库存）
- **设置装备**：选择玩家 + 槽位（验证类型匹配：右臂→右臂），设置到框架区域
- **弃置装备**：从指定区域移除并弃置，或弃置未设置库存
- **损伤调整**：逐个增加/减少任意槽位的损伤标记

### 3. 玩家修改器
- 直接修改数值：护甲、动力、金币、生命、攻击次数限制等
- 输入字段 + 增减按钮

## 实施步骤

### Step 1: 创建 DeveloperDebugPanel.tscn + .gd
- 开发者工具根面板，作为ModeSwitch或快捷键呼出
- 三个Tab页面：行动牌、装备/框架、修改器

### Step 2: 实现 ActionCardDebugTab
- 玩家下拉选择
- 卡牌ID输入 + 获得按钮
- 弃置数量输入 + 弃置按钮
- 牌堆显示（只读）

### Step 3: 实现 EquipmentDebugTab
- 玩家下拉选择
- 装备ID输入 + 获得（未设置）按钮
- 槽位下拉 + 设置按钮
- 槽位选择 + 损伤 +/- 按钮
- 弃置按钮（按槽位/全部库存）

### Step 4: 实现 PlayerModifierTab
- 玩家下拉选择
- 数值字段：护甲、动力、金币、HP、攻击限制
- 增减按钮 + 直接输入

### Step 5: 集成到游戏
- 在 app_root.gd 添加快捷键呼出开发者面板（~键或F12）
- 或在主菜单添加"开发者模式"入口
