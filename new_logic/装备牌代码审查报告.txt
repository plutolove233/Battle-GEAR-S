████【MAJOR-1】056 帝国的赤枭·躯干  (effect_040 DIRECT + effect_041 LISTEN) ████████
权威效果文本：
  每回合1次，可以弃置X数量的行动牌（X最低为1），当前回合动力+2倍X的数值，
  此效果可以在使用迎击牌时使用。
当前代码行为（GeneratedEquipmentEffects.gd L1178-1241）：
  effect_040（主阶段 DIRECT）/ effect_041（迎击 LISTEN USE_ACTION_AT）均用
  CHOOSE_INTEGER 选 n → SPEND_GOLD 2*n 金币 → EXECUTE_STAT_MODIFY 动力+n。
  即「花 2n 金币，动力+n」，资源是【金币】，倍率是【1倍】。
偏差：
  ① 资源错误：权威是【弃置行动牌】，代码是【消耗金币】。
  ② 倍率错误：权威动力加成是【+2X】，代码是【+n】（1倍）。
  ③ 两者共享 once_per_turn_key="red_owl_torso_gold_power"（每回合1次，主阶段/迎击共享），
     这部分符合权威「此效果可以在使用迎击牌时使用」。
正确逻辑：
  每回合1次（主阶段或使用迎击牌时），选 X（X≥1，上限=当前行动牌手牌数），
  弃置 X 张行动牌，本回合动力 +2X。
修复方案：
  - effect_040 / effect_041 的 actions 把 CHOOSE_INTEGER 的：
      max_value_expr: "floor($binding_context.owner_gold / 2)"
      actions: [SPEND_GOLD 2*n, STAT_MODIFY power value_expr=$choice.n]
    改为：
      max_value_expr: "$binding_context.owner_action_hand_count"  ← 需新增此 binding
      actions: [
        {"type": &"DISCARD_ACTION_CARD", "params": {"count_expr": "$choice.n", "player_id": "$binding_context.player_id"}},
        {"type": &"EXECUTE_STAT_MODIFY", "params": {"target_id": "$binding_context.mech_id", "stat_type": &"power", "value_expr": "2 * $choice.n", "method": &"add", "duration": &"THIS_TURN"}}
      ]
  - 条件 GOLD_ABOVE threshold=2 改为 OWNER_ACTION_HAND_ABOVE threshold=1（至少1张才能弃）。
  - 需在 ActionService._resolve_atomic_value / binding_context 注入 owner_action_hand_count
    （玩家行动手牌数）。label 文案改为「弃置 n 张行动牌，本回合动力+2n」。
  - once_per_turn_key 保留不变。
  - 同步更新 effect_040/041 的 description 与 display_name（金币→行动牌）。
影响测试：test_equipment_effects.gd 中 red_owl 相关结构断言可能需更新文案。

████【MEDIUM-4】119 联邦的一角兽·右腿  (effect_084) ██████████████████████████
权威效果文本：
  响应对我方的攻击，可以设置2损伤到此牌上，机甲可立即移动2个格子。
  发动此效果后，可以立即继续发动此效果。
当前代码行为（L2278-2308 + TimingEngine.gd L2104-2129）：
  AVAILABILITY 响应攻击 → RESPOND_ATTACK + REPEAT_SELF_DAMAGE_AND_FREE_MOVE。
  但 REPEAT_SELF_DAMAGE_AND_FREE_MOVE 在 TimingEngine 是【单轮】实现：
  注释明写「单轮：fixed_slot 自损 + free_move 移动。（"可继续发动"循环待实机/F3 补）」。
  即只自损2+移动2一次，不循环。
偏差：权威「发动此效果后，可以立即继续发动此效果」的【循环】未实现。
正确逻辑：每次发动=自损2+免费移动2格；发动完后可再次发动（直到玩家取消/无格可移/
         自损致本牌弃置/无法再承受损伤）。
修复方案：
  在 TimingEngine REPEAT_SELF_DAMAGE_AND_FREE_MOVE 分支末尾，当 allow_continue=true
  且来源牌仍在槽（stop_if_source_leaves_slot 校验）且仍可承受损伤（SELF_DAMAGE_TOKENS_BELOW
  门槛）时，重新挂起一次 need_input「是否继续发动？」，玩家确认则再次执行自损2+移动2，
  取消则结束。可用现有 CHOOSE_ONE optional 机制循环；或新增一个 loop 计数挂在 action.record。
  注意每次循环都要重新校验 SELF_DAMAGE_TOKENS_BELOW threshold=5（自损2后若≥耐久会弃置，
   应停止——已有 _source_equipment_discarded 守卫可复用）。
  同步 TimingEngine 注释去掉「单轮」。
