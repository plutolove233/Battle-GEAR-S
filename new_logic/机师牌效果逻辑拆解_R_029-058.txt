========================================================================
适用范围与共同约定
========================================================================
1. 本文只使用新 Action + Timing 体系；不调用旧 hook / legacy CardEffect / CUSTOM_EFFECT_CHECK_TEXT。
2. 机师设置到 slot_id=&"pilot" 后，LISTEN / AVAILABILITY / DIRECT 均按 card_instance_id 注册；更换机师时先注销旧实例全部 permanent listener，再注册新实例。
3. “可以/可”均提供取消路径。取消且尚未提交成本、牌转移或数值变动时，不消耗限次；不可逆子动作已结算后取消不回滚。
4. “每回合”按当前活动玩家的回合分别计数；“我方回合”只允许机师拥有者回合发动。
5. “当作”是出牌前转化：虚拟牌无实体、无行动牌类型，不触发 USE_ACTION_*；攻击类仍是主动攻击并消耗回合攻击数，迎击类只能在 ATTACK_AT 响应。
6. “立即使用”实体行动牌走完整 use_action_card 链；由效果引出的攻击标记 passive=true，不消耗回合攻击数，但仍校验武器与合法目标。
7. “X格范围”使用 _HexGrid.distance，不使用攻击范围 BFS。武器范围加成则接入攻击范围查询链。
8. 动态值使用 "$payload.xxx" / "$binding_context.xxx" / "$result.xxx"；ActionEngine 在执行时解析。
9. 同一技能跨多个时点时，通过 attack_id / discard_action_id / gain_action_id 及 record flag 绑定，禁止用“最近一次动作”全局变量猜测。
10. 四份权威文档没有给出项目当前 pilot JSON / 旧 GeneratedPilotEffects.gd 的完整 effect_ids 数组。本文给出按既有命名格式可落码的“本拆解 effect_ids”；合入时只允许做 ID 名称映射，不得根据旧占位行为反改本文逻辑。
11. 《行动牌的效果与逻辑》未提供“设陷”的完整基础效果链。pilot_057 只定义转化调用和陷阱移动扩展，不臆造设陷牌基础行为。
12. 规则书定义商店购买，但四份文档未给出完整“卖出装备”“事件牌设置/失去”的动作生命周期。本档相关牌明确列出需新增时点及记录字段。

[机师牌 029] 克劳德  （阵营:联邦 稀有度:R 费用:6 行动牌上限:4 回合攻击数:1）
═══════════════════════════════════════════════════════════
效果文本：我方远程武器范围+1。
我方回合1次，可以将1张行动牌当作聚能使用。
本拆解 effect_ids：["pilot_029_effect_01","pilot_029_effect_02"]

──────────── 效果拆解（pilot_029_effect_01 远程武器范围+1）────────────
首句：派生值型，不注册监听器。查询武器有效范围时实时重算。

类型：派生值 / 装备属性修正
helper：PilotDerivedStats.get_weapon_range_bonus(mech_id, weapon_instance_id)
接入点：
- WeaponState.get_effective_range()
- AttackService 选武器后写入 attack.record.base_range / effective_range
- 攻击牌可用性预检的“最大可能范围”计算

公式：
```
bonus = 1 if (
  pilot_029当前正面设置于该mech的pilot槽
  and weapon.weapon_kind == &"RANGED"
) else 0
effective_range = weapon_base_range + equipment_modifiers + status_modifiers + bonus
```
统计口径：只检查攻击实际选中的武器类型；特殊武器不因名称或标签看似远程而自动命中，必须由 weapon_kind=&"RANGED" 判定。

人类 UI：按钮1置灰；显示“远程武器范围 +1”。武器卡及攻击预览面板显示修正后的有效范围。

──────────── 顺序与坑 ────────────
- 范围+1不是临时 status，也不随回合清除；换下克劳德后立即从查询结果消失。
- 聚能转化不是使用辅助行动牌，不触发“使用辅助牌时”类效果。
- 聚能层数仍按被选武器实例独立；武器被替换或弃置时按聚能既有清理规则处理。
- 对“被临时转换为远程”的武器，查询当前 effective weapon_kind；若转换动作明确改 weapon_kind，则可获得+1。

场景d：无武器

  断言：按钮禁用。
场景e：换机师
  操作：克劳德换为其他机师。
  断言：远程范围即时恢复原值；已存在聚能状态按状态自身规则保留或清理，不由派生值helper处理。

歧义点：

──────────── 实现预告 ────────────
- 新增/复用 CALCULATE_SELF_DAMAGE_TOKENS，统计区域damage_tokens总和，包括装备已弃但保留在槽位区域上的损伤。
- 值解析支持count_expr；或用SET_VARIABLE + arithmetic evaluator。
- EXECUTE_DISCARD count=0时直接no-op，不弹窗。
- 需重写旧 pilot_044 占位。

──────────── 顺序与坑 ────────────
- TURN_START位于常规回合抽牌之前，因此先结算索伦，再进行规则抽2行动牌等TURN_AFTER_START内容。
- TURN_AFTER_END晚于常规手牌上限清理；本技能结束后新手牌可暂时超过上限，直到下次对应清理。
- X是每次触发的局部快照，不是本局持续变量。
- 抽牌期间若触发其他效果设置/移除损伤，不改变本次需弃数量。
- 若牌堆不足导致实际抽牌少于X，仍按记录X弃牌；实际手牌不足时弃置全部并记录shortfall，不产生额外惩罚。

──────────── 测试场景 ────────────
场景a：开始时X=3
  操作：TURN_START。
  断言：先抽4，再选弃3；随后才进入常规回合抽牌。

  断言：抽1，不弹弃牌窗。
场景c：结束后
  前置：常规超限清理完成后X=2。
  断言：抽3、弃2；新手牌不再次触发同回合上限清理。
场景d：中途损伤变化
  前置：快照X=2，抽牌监听移除1损伤。
  断言：本次仍弃2。
场景e：弃牌窗取消
  断言：此处为强制弃置，不提供取消；必须选足X或全部可用牌。

[歧义2] TURN_AFTER_END抽牌后是否立即再做一次上限清理。智能体选择：不做（理由：该技能发生在规则清理后的时点，生命周期没有第二次清理步骤）。候选：技能结算后立即按上限弃牌。▶ 回答：_智能体选择正确___________________
